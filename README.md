# Tender Parser — автоматический анализ тендеров

Программа принимает архив с тендерами, извлекает из документов текст и с помощью ИИ заполняет таблицу Excel (поля указываются в файле config.yaml) — по одной строке на каждый тендер.

---

## Что нужно установить один раз

### 1. Python
Скачайте и установите с сайта [python.org](https://python.org) (версия 3.10 или новее).

### 2. unar — для работы с RAR-архивами

**Mac:**
```bash
brew install unar
```

**Windows:** скачайте `unrar.exe` с [rarlab.com](https://www.rarlab.com/rar_add.htm) и добавьте папку с ним в системный PATH.

### 3. LibreOffice — для чтения старых .doc файлов
Скачайте и установите с сайта [libreoffice.org](https://libreoffice.org) (бесплатно).

---

## Первый запуск — настройка проекта

Откройте терминал, перейдите в папку с программой и выполните по очереди:

```bash
# Создать виртуальное окружение
python -m venv .venv

# Активировать его
# На Mac / Linux:
source .venv/bin/activate
# На Windows:
.venv\Scripts\activate
```

После этого в начале строки терминала появится `(.venv)`.

```bash
# Установить все зависимости
pip install -r requirements.txt
```

## Настройка

### Изменить список полей в Excel

Откройте файл `config.yaml` и найдите раздел `fields`. Каждый элемент — это одна колонка в итоговой таблице:

```yaml
fields:
  - name: позиции
    description: все закупочные позиции с количеством и ценами
    merge: concat
  - name: номер_тендера
    description: номер извещения или реестровый номер закупки
  # ... всего 9 полей
```

Чтобы **добавить поле** — добавьте новый элемент с `name` (имя колонки) и `description` (подсказка для ИИ что именно искать). Чтобы **убрать поле** — удалите или закомментируйте строки (поставьте `#` в начале). Больше ничего менять не нужно.

### Для работы через локальную модель (Ollama) (не рекомендуется)
Установите [Ollama](https://ollama.com) и скачайте модель:
```bash
ollama pull gemma3:4b
```
Больше ничего не нужно — ключи не требуются.

### Для работы через интернет (OpenRouter / ChatGPT / ...)
Скопируйте файл с настройками и вставьте ключ:
```bash
cp .env.example .env
```
Откройте файл `.env` в любом текстовом редакторе и замените `sk-...` на ваш ключ API.

## Как запустить

Убедитесь что виртуальное окружение активировано (в начале строки есть `(.venv)`).

### Шаг 1 — проверить что текст извлекается правильно

```bash
python tender.py --input /путь/до/архива.rar
```

Программа создаст рядом с архивом папку `архив_parsed/` и положит туда `.txt`-файлы с текстом каждого тендера.

### Шаг 2 — анализ через локальную модель

```bash
python tender.py --input /путь/до/архива.rar --mode ollama
```

### Шаг 3 — анализ через интернет (быстрее и точнее)

```bash
python tender.py --input /путь/до/архива.rar --mode api
```

Результат — файл `result.xlsx` в той же папке `архив_parsed/`. Открывается в Excel или Google Таблицах.

---

## Если что-то пошло не так

Все ошибки записываются в файл `logs/errors.log`. Откройте его и посмотрите какие файлы не удалось обработать и почему.

Если архив большой и вы хотите сначала обработать несколько тендеров для проверки — просто остановите программу (`Ctrl+C`) и откройте уже созданный `result.xlsx`.

---

## Повторный запуск

Если `.txt`-файлы уже созданы — она не будет извлекать текст заново, а сразу перейдёт к анализу. Если в `result.xlsx` уже есть строки — дозапишет только новые, не сотрёт старые.

---

## Пример типичной работы

```
# Шаг 1 — смотрим на качество текста
python tender.py --input ~/Downloads/Деревья.rar

# Всё хорошо, запускаем анализ
python tender.py --input ~/Downloads/Деревья.rar --mode ollama

# Открываем результат
open ~/Downloads/Деревья_parsed/result.xlsx
```
