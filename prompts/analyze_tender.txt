Правила извлечения:
1. Приоритет источников — ИЗВЕЩЕНИЕ о закупке. Только если в извещении нужного поля нет — смотреть проект контракта, ТЗ, описание объекта закупки.
2. "номер_тендера" — это "Номер извещения" (короткий код, обычно 18-19 цифр или формат типа "246871-26LO"). НЕ путать с ИКЗ (идентификационный код закупки) — он длиннее (35+ символов) и идёт в отдельном поле извещения.
3. "позиции":
   - тендер на товары — каждая позиция с новой строки в формате из описания поля;
   - тендер на работы или услуги — одна строка: название работ + (1 шт., цена ₽/шт., цена ₽).
4. Числовые поля ("общая_цена", "начальная_цена") — только число, без валюты ("РОССИЙСКИЙ РУБЛЬ", "₽", "руб.") и без единиц измерения.
5. Если данных в тексте нет — оставить пустую строку "". НЕ придумывать значения и НЕ выводить "Не указано", "Информация отсутствует" и т.п.
6. "категория_заказчика" — "государство" для ФГБУ / ГБУ / ГУП / МУП / МКУ / администраций / министерств / АО с госучастием. "частник" для коммерческих ООО / ИП / частных АО.
